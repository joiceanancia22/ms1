DOCKER CLI – IMPORTANT VIVA QUESTIONS AND ANSWERS

1. BASIC DOCKER CONCEPTS

1. What is Docker?
Docker is a platform used to build, package, and run applications inside containers.

2. What is a container?
A container is an isolated environment that runs an application and its dependencies.

3. What is a Docker image?
A Docker image is a read-only template used to create containers.

4. What is the difference between an image and a container?
An image is a template, whereas a container is an instance created from that image.

5. What is Docker Engine?
Docker Engine is the software that builds and runs Docker containers.

6. What is Docker Hub?
Docker Hub is a registry used to store and share Docker images.

7. What is a Docker registry?
A registry stores and distributes Docker images.

8. What is the difference between Docker and a virtual machine?
Containers share the host operating system kernel, whereas virtual machines run separate guest operating systems.

9. What is Docker CLI?
Docker CLI is a command-line interface used to interact with Docker.

10. What is the use of docker --help?
It displays available Docker commands and options.

2. DOCKER IMAGE COMMANDS

11. What is the use of docker pull nginx?
It downloads the Nginx image from a registry.

12. What is the use of docker images?
It lists locally available Docker images.

13. What is the use of docker search nginx?
It searches for Nginx images on Docker Hub.

14. What is the use of docker image inspect nginx?
It displays detailed information about the image.

15. What is the use of docker tag?
It assigns another name or tag to an image.

16. What is the use of docker rmi nginx?
It removes the specified image if it is not being used by a container.

17. What is the difference between docker pull and docker push?
Pull downloads an image, whereas push uploads an image to a registry.

18. What is the use of docker save and docker load?
Docker save saves an image to a tar archive, and docker load loads an image from an archive.

19. What is an image tag?
A tag identifies a particular version or variant of an image, such as nginx:alpine.

20. What is the use of docker history nginx?
It displays the image's build history and layers.

3. CONTAINER COMMANDS

21. What is the use of docker run?
It creates and starts a container from an image.

22. What is the use of -d?
It runs a container in detached or background mode.

23. What is the use of -it?
-i keeps standard input open, and -t allocates a terminal.

24. What is the use of --name?
It assigns a name to the container.

25. What is the difference between docker run and docker start?
Docker run creates and starts a new container, whereas docker start starts an existing stopped container.

26. What is the difference between docker stop and docker kill?
Docker stop requests a graceful shutdown, whereas docker kill sends a termination signal immediately by default.

27. What is the difference between docker ps and docker ps -a?
Docker ps lists running containers, whereas docker ps -a lists all containers, including stopped containers.

28. What is the use of docker exec?
It executes a command inside a running container.

29. What is the difference between docker exec and docker attach?
Docker exec starts a separate process inside the container, whereas docker attach connects to the main process's input and output streams.

30. What is the use of docker logs?
It displays the available logs of a container.

31. What is the use of docker inspect?
It displays detailed configuration and runtime information about a container or image.

32. What is the use of docker stats?
It displays container resource usage, including CPU and memory.

33. What is the use of docker port?
It displays the port mappings of a container.

34. What is the use of docker rm -f CONTAINER?
It forcefully removes a container, stopping it first if necessary.

35. What is the use of --rm in docker run?
It automatically removes the container after it exits.

4. DOCKER NETWORKING

36. What is Docker networking?
It allows containers to communicate with one another and with external systems.

37. What are the common Docker network drivers?
Bridge, host, none, overlay, and macvlan.

38. What is a bridge network?
It connects containers on the same Docker host through a virtual network.

39. What is the use of docker network ls?
It lists Docker networks.

40. What is the use of docker network create mynet?
It creates a user-defined bridge network by default.

41. What is the use of docker network inspect mynet?
It displays network configuration and connected containers.

42. How do you connect a container to a network?
Use docker network connect NETWORK CONTAINER.

43. How do you disconnect a container from a network?
Use docker network disconnect NETWORK CONTAINER.

44. How do two containers communicate on the same user-defined bridge network?
They can communicate using their container names or IP addresses, subject to network configuration.

45. How do you test communication between two containers?
Use docker exec c1 ping -c 4 c2, provided ping is installed and ICMP traffic is permitted.

46. How do you check a container's IP address?
Use docker inspect and examine NetworkSettings.Networks.

47. Can containers on separate networks communicate directly by container name?
Generally, no. They need a shared network or another configured routing and name-resolution mechanism.

48. How do you enable communication between containers on separate networks?
Connect one container to the other network using docker network connect.

49. What is the difference between bridge and host networking?
Bridge networking uses a separate container network, whereas host networking shares the host's network namespace where supported.

50. What is the use of --network none?
It disables normal container networking.

51. What is port mapping?
It forwards a host port to a container port. For example, -p 8080:80 maps host port 8080 to container port 80.

52. What is the difference between EXPOSE and -p?
EXPOSE documents a container port, whereas -p publishes a port on the host.

53. What is the default Docker bridge?
It is Docker's built-in bridge network named bridge.

54. What is the difference between the default bridge and a user-defined bridge?
User-defined bridges provide automatic container-name DNS resolution and network-specific configuration.

55. What is an overlay network?
It connects containers across multiple Docker hosts and is commonly used with Docker Swarm.

5. VOLUMES AND BIND MOUNTS

56. What is a Docker volume?
A Docker volume is storage managed by Docker that can persist beyond a container's lifecycle.

57. Why are volumes used?
They persist data, share data between containers, and separate storage from container lifecycles.

58. What is the use of docker volume create mydata?
It creates a named volume.

59. What is the difference between a volume and a bind mount?
A volume is managed by Docker, whereas a bind mount maps a specified host filesystem path into a container.

60. What is the use of docker volume ls?
It lists Docker volumes.

61. Does removing a container delete its named volume?
Normally, no. The volume remains unless explicitly removed or otherwise managed.

62. What does docker compose down -v do?
It removes Compose-managed containers and networks and also removes declared named volumes and attached anonymous volumes.

6. DOCKERFILE AND IMAGE BUILDING

63. What is a Dockerfile?
A Dockerfile is a text file containing instructions to build a Docker image.

64. What is the use of docker build -t myapp:v1 .?
It builds an image and tags it myapp:v1 using the current directory as the build context.

65. What does the dot (.) mean in docker build?
It specifies the current directory as the build context.

66. What is the difference between RUN and CMD?
RUN executes commands during image building, whereas CMD specifies the default command or arguments when a container starts.

67. What is the difference between CMD and ENTRYPOINT?
CMD provides default commands or arguments, whereas ENTRYPOINT defines the main executable.

68. What is the use of FROM?
It specifies the base image.

69. What is the use of WORKDIR?
It sets the working directory for subsequent Dockerfile instructions.

70. What is the use of COPY?
It copies files from the build context into the image.

71. What is the use of ENV?
It sets environment variables in the image.

72. What is the use of .dockerignore?
It excludes specified files and directories from the build context.

73. What is the use of docker build --no-cache?
It builds without reusing cached build layers.

7. DOCKER COMPOSE

74. What is Docker Compose?
It is a tool for defining and running multi-container applications using a YAML configuration file.

75. What is the use of compose.yaml?
It defines services, networks, volumes, and other application configuration.

76. What is the use of docker compose up -d?
It creates and starts application services in the background.

77. What is the use of docker compose down?
It stops and removes application containers and Compose-managed networks.

78. What is the use of docker compose ps?
It lists containers belonging to the Compose project.

79. What is the use of docker compose logs -f?
It follows service logs in real time.

80. What is the difference between docker compose stop and docker compose down?
Stop stops services but retains their containers. Down also removes the project's containers and networks.

81. How do services communicate in Docker Compose?
Services on the same Compose network can generally communicate using their service names and container ports.

82. What is the use of docker compose config?
It validates and displays the resolved Compose configuration.

8. SYSTEM CLEANUP AND DOCKER SWARM

83. What is the use of docker system df?
It displays Docker disk usage.

84. What is the use of docker system prune?
It removes unused Docker resources according to its cleanup rules.

85. What does docker system prune -a do?
It also removes unused images, not just dangling images.

86. What is Docker Swarm?
It is Docker's native container orchestration mode for managing services across a cluster.

87. What is a Swarm service?
It is a declarative definition of a workload that Docker Swarm manages across its nodes.

88. What is the use of docker swarm init?
It initializes a new Swarm and makes the current node a manager.

89. What is the use of docker service scale web=3?
It sets the desired replica count of the web service to three.

90. What is the difference between a container and a service in Swarm?
A container is an individual instance, whereas a service defines the desired workload and can manage multiple replicas.
